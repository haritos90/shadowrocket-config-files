# Contributing

This repository holds a small set of Shadowrocket configuration profiles.
Suggestions and fixes are welcome through issues and pull requests.

## Changing a profile

The tracked files are the `.conf` profiles and the README that documents them.
When you change a profile, keep the README parameter description in sync, and
note which Shadowrocket version you tested against — the config format shifts
between parser versions.

## Commits

Keep each change focused, with a clear, imperative commit summary.

## AI-assisted contributions

Using an AI assistant is welcome. Review and understand every line you submit,
confirm the profile still parses in Shadowrocket, and be ready to answer review
questions — the model having written it is not a defense.
